# 🔐 OffSec Learning Journey

> Learning offensive security by understanding how systems work, how they break, and how to secure them.

This repository documents my journey into **Offensive Security and Cybersecurity**.

I'm using it to keep track of labs, notes, tools, scripts, CTF challenges, experiments, and lessons learned along the way.

The goal isn't just to run tools.

It's to understand **what the tools are doing, why a technique works, and how the underlying vulnerability can be identified and fixed.**
